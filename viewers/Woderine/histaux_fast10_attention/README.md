# Woderine：histaux 逐时刻注意力

[打开交互网页](https://woderine.github.io/disruption-result/viewers/Woderine/histaux_fast10_attention/) · [返回结果画廊](https://woderine.github.io/disruption-result/)

本页包含 10 个目标快炮的三头预测曲线、每个时刻按速率头单历史门权排序的前 30 条历史炮，以及绘图所需的 2,256 炮六通道波形 JSON。预测沿用原查看器的逐时刻速率头 top-6 融合结果。每个时刻只列出更早炮号。

选择目标炮、拖动时间滑块或使用左右方向键，点击左侧历史炮即可查看波形；Shift 加方向键移动 10 个时间点。画廊展开对应炮号后可直接进入该炮；链接中的 `#shot=16845` 保存目标炮。

`data.json` 保存预测与排序；`waves/<shot>.json` 保存 IP、CCIP、ZP、RP、AXUV001、AXUV016 的绘图数据，按需加载。页面和这些数值数据已由作者确认允许公开。门权是模型内部权重，本页用于读图，选定炮次不代表全量测试统计结论。
